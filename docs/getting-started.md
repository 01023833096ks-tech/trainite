# Getting Started


This guide will walk you through installing Trainite, initializing a new project, and running your first training execution.

---

## 1. Prerequisites

Before installing Trainite, ensure you have the following installed:

- **Python 3.9+**
- `pip` or `uv` package manager

---

## 2. Installation

Install Trainite directly using `pip`:

```bash
pip install trainite
